## The problem
Over 80% of the deep ocean is unexplored and unmonitored, while illegal dumping, plastic accumulation, ghost fishing nets, coral bleaching and species decline accelerate — largely undetected until the damage is irreversible.

## The solution
DeepSea Guardian unifies drones, sonar, satellite and IoT data into one real-time dashboard that detects threats, tracks biodiversity, and **predicts** environmental risk.

## ⭐ Signature — Ocean Health Index
A single AI-fused **0–100 score per ocean zone** distilling four threat signals (plastic, bleaching, ghost nets, risk) into one actionable number, colour-banded and auto-alerting.

## Features
- Live monitoring dashboard — KPIs, AI detection feed, Ocean Health Index gauge, styled risk map
- Predictive risk heatmap with per-zone health scores
- Biodiversity tracker for endangered species
- Alerts & reports with filtering
- Fully responsive · SEO-optimized · accessible

## Tech stack
React 19 · Vite · React Router · Tailwind CSS v4 · Recharts · Framer Motion · lucide-react · deployed on Vercel. Hardcoded mock data (no backend, per rules).

## Run locally
```bash
git clone https://github.com/dronadri2007/Deepsea-Guardian.git
cd Deepsea-Guardian
npm install
npm run dev
```
